ℹ️ Structure Guide
📦 Asset Folder Directory Structure

Upload a structured folder or .zip package to automatically populate references, playlists, optional lore/ text documents, and canvas defaults.

📁 my_theater_assets/
├── 📁 references/ (Images: .png, .jpg, .webp)
│ ├── hero_portrait.png
│ └── desert_map.jpg
├── 📁 playlists/ (Audio folders = playlist names)
│ ├── 📁 ambient/
│ │ └── desert_wind.mp3
│ └── 📁 combat/
│ └── battle_theme.wav
└── 📄 theater.yaml (Required theater configuration)
⚡ Auto-Extraction: References and audio tracks are parsed & mounted instantly. Put character and world background in lore/ as UTF-8 .txt files; the story planner can browse them when creating characters.
💡 Pro tip: Export an existing theater, edit its assets or theater.yaml, then upload it here to create a revised copy.
📦 ZIP Support: You can drop an uncompressed folder or a compressed .zip file directly.

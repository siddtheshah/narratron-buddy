ℹ️ Structure Guide
📦 Asset Folder Directory Structure

Upload a structured folder or .zip package to automatically populate references, playlists, and canvas defaults.

📁 my_theater_assets/
├── 📁 references/ (Images: .png, .jpg, .webp)
│ ├── hero_portrait.png
│ └── desert_map.jpg
├── 📁 playlists/ (Audio folders = playlist names)
│ ├── 📁 ambient/
│ │ └── desert_wind.mp3
│ └── 📁 combat/
│ └── battle_theme.wav
└── 📄 style.txt (Optional default style prompt)
⚡ Auto-Extraction: References, audio tracks, and style prompts are parsed & mounted instantly.
📦 ZIP Support: You can drop an uncompressed folder or a compressed .zip file directly.

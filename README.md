# Narratron Buddy: Agentic Web Canvas

This project uses the Google Agent Development Kit (ADK) and Gemini Live API to create an interactive agent. It features a FastAPI web interface to provide a collaborative doodle canvas and display images generated by the agent.

## Prerequisites
- Python 3.10+
- Windows (PowerShell examples below)

## Install

```powershell
python -m venv .venv
. .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Gcloud Setup

You will need a GCloud project to use the Gemini Live API via Vertex AI.

To get started with GCloud, complete the following steps:
1. Install GCloud CLI: https://cloud.google.com/sdk/docs/install
2. Run `gcloud init` to login and set your default project
3. Run `gcloud auth application-default login` to grant Python local access to your credentials

## Running the App

### Start the Skeleton ADK Agent
```powershell
python agent.py
```

### Start the Web Viewer
```powershell
python web_viewer_app.py
```

## Exporting the Frontend

You need to set up ngrok to expose the frontend. https://dashboard.ngrok.com/get-started/setup
Create a username and password in your `ngrok_policy.yaml`. This will prevent you getting DDOS'd by random people.

```powershell
ngrok http 8000 --traffic-policy-file ngrok_policy.yaml
```
